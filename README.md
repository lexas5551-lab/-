# ГНВП-тест

Android-приложение для обучения и проверки знаний: 145 вопросов, пояснения к ответам, тесты, билеты, повторение ошибок и статистика.

В разделе «Вопросы» доступны переходы назад и вперёд. Ответы и последний вопрос сохраняются на устройстве, сброс доступен в настройках вопросов.

26 иллюстраций: 21 готовое изображение к вопросам №1–10 и №70–80 и 5 ранее добавленных схем №102–106. Изображения открываются после ответа и увеличиваются до 400%. Отдельного раздела иллюстраций в меню нет.

Название: ГНВП-тест. Версия: 1.0. Android 7.0 и новее. Работает офлайн.

GitHub Actions собирает APK и проверяет запуск и сохранение ответов на Android 15. Release APK подписывается локально после сборки. Приватный ключ не входит в проект и не публикуется в репозитории.
