# ГНВП и ГОР — Android-тренажёр

Тестовая версия Android-приложения на базе **145 исходных вопросов**: 120 ГНВП + 25 ГОР.

## Что реализовано

- **Прорешивание**: ответ проверяется сразу; при ошибке вопрос остаётся на экране и его можно решить повторно. Правильный вариант не раскрывается автоматически.
- **Тест**: случайная выборка 10/20/25/50/100/145 вопросов. Результат и разбор — в конце.
- **Билет**: 10 случайных вопросов из общего банка 145.
- **Ошибки**: отдельное повторение вопросов, на которых пользователь ошибался.
- **Статистика** хранится локально на телефоне.
- Поддерживаются вопросы с **несколькими правильными вариантами**.
- Работает **офлайн**, разрешение INTERNET не используется.
- Для части технических вопросов подключены справочные иллюстрации. Они показываются после ответа, чтобы не подсказывать заранее.

## Критическое правило данных

`app/src/main/assets/questions.js` сформирован из `source/Исходный_банк_145_вопросов.xlsx`.
Текст вопросов, варианты ответов и их порядок в приложении **не изменяются**. В тесте и билетах перемешиваются только вопросы.

Отчёт автоматической сверки находится в `ПРОВЕРКА_БАНКА.txt`.

## Самый простой способ получить APK — GitHub Actions

1. Создайте пустой репозиторий на GitHub.
2. Загрузите **всё содержимое этой папки** в корень репозитория.
3. Откройте вкладку **Actions**.
4. Выберите workflow **Build Android APK**.
5. Нажмите **Run workflow**.
6. После завершения откройте выполненный запуск и внизу страницы скачайте artifact **GNVP-GOR-debug-apk**.
7. В архиве будет `app-debug.apk`. Перенесите его на Android-телефон и установите.

GitHub сам скачает Android Gradle Plugin и Gradle. Локально Android Studio для этого способа не требуется.

## Сборка через Android Studio

1. Установите актуальную Android Studio.
2. Убедитесь, что установлен **JDK 17** и Android SDK **35**.
3. Распакуйте проект и в Android Studio выберите **Open** → папка проекта.
4. Дождитесь окончания Gradle Sync.
5. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для публикации/постоянной установки используйте **Build → Generate Signed Bundle / APK** и создайте собственный keystore.

## Где менять название/версию

- Название: `app/src/main/AndroidManifest.xml`
- Версия: `app/build.gradle` (`versionCode`, `versionName`)
- Внешний вид и логика: `app/src/main/assets/index.html`
- Банк: `app/src/main/assets/questions.js`
- Иллюстрации: `app/src/main/assets/images/`

## Как добавлять новые изображения

1. Положите PNG/JPG в `app/src/main/assets/images/`.
2. В нужном объекте `questions.js` заполните поле, например: `"image":"images/my_picture.png"`.
3. Иллюстрация появится только после правильного ответа/показа ответа в прорешивании и в разборе результата теста.

**Не вставляйте вопрос или варианты ответов текстом внутрь изображения.** Текст должен отображаться из `questions.js`, чтобы сохранять 100% соответствие исходному банку.
